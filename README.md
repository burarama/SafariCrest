# 🦁 Safari Crest - Responsible Ecotourism Kenya

[![License: MIT](https://img.shields.io/badge/License-MIT-green.svg)](https://opensource.org/licenses/MIT)
[![HTML5](https://img.shields.io/badge/HTML5-Semantic-orange.svg)](https://developer.mozilla.org/en-US/docs/Web/HTML)
[![CSS3](https://img.shields.io/badge/CSS3-Flexbox%20%26%20Variables-blue.svg)](https://developer.mozilla.org/en-US/docs/Web/CSS)

**Safari Crest** is a modern, fully responsive, multi-page web application dedicated to sustainable ecotourism, community alliances, and active wildlife conservation in Kenya. It bridges high-impact adventure travel with grassroots environmental preservation.

---

## ✨ Key Features

* **Cinematic Hero Section:** Immersive HTML5 video background featuring a multi-stop dark gradient overlay and custom entrance animations.
* **Responsive Mobile Navigation:** Seamlessly transforms from a sticky desktop horizontal menu into a clean, smooth-sliding mobile hamburger drawer ("three lines" toggle).
* **Consistent Design System:** Built around a custom CSS theme palette (`--primary-color`, `--secondary-color`, `--bg-canvas`, and `--text-main`) capturing natural East African aesthetics (Deep Forest Green & Earthy Terracotta).
* **Multi-Page Architecture:** 
  * `index.html` — Engaging landing page showcasing core conservation pillars.
  * `services.html` — Detailed ecotourism experiences featuring inline video elements and guided trail options.
  * `about.html` — Mission statement, origin story, and environmental education frameworks.
  * `contact.html` — Conservation hub location details paired with a clean inquiry interface form.
